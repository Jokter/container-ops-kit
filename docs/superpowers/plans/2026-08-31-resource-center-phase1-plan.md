# 资源中心第一阶段开发计划

> 对应设计：docs/superpowers/specs/2026-08-30-resource-center-phase1-design.md
> 目标：实现环境配置持久化与真实 SSH 测试

## 1. 代码基线与目录准备

1. 保留现有 `index.html` 原型，新增正式前后端目录。
2. 创建根 Maven 配置和 `backend` Spring Boot 模块。
3. 创建 `frontend` Vue 3 + TypeScript + Vite 工程。
4. 配置开发代理，让前端通过 `/api` 访问后端。
5. 配置统一错误响应、CORS 和健康检查。

验收：前端和后端可以独立启动，健康检查返回成功。

## 2. 后端领域与持久化

1. 创建发布版本、环境、容器连接配置领域模型。
2. 创建 BUILD、CONTAINER、X86_64、AARCH64 和连接状态枚举。
3. 创建 Spring Data JPA Repository。
4. 创建 Flyway 初始迁移。
5. 初始化 R27C10 和 R27C00。
6. 配置 H2 文件数据库路径为 `data/resource-center`。
7. 实现环境新增、查询、详情、更新、删除。
8. 实现乐观锁版本校验。
9. 在 SSH 地址、端口或密码变化时重置连接状态。
10. 删除环境时级联删除对应容器配置。

验收：重启服务后数据保留，CRUD 和并发版本冲突行为正确。

## 3. SSH 测试

1. 引入成熟 Java SSH 客户端。
2. 根据环境类型派生固定用户名：
   - BUILD：`huawei`
   - CONTAINER：`sopuser`
3. 实现保存前配置测试。
4. 实现已保存环境测试。
5. 实现批量测试，限制最大并发数为 5。
6. 设置连接和认证超时。
7. 区分 DNS、超时、拒绝连接、认证失败、协议错误和未知错误。
8. 成功时记录状态、时间和耗时。
9. 失败时记录状态、时间、耗时和简短错误信息。
10. 不记录测试历史，不执行远端命令，不把密码写入日志。

验收：使用真实 SSH 服务验证成功和失败场景；环境状态只显示未测试、可连接、连接失败。

## 4. REST API

1. 实现发布版本接口。
2. 实现环境列表查询、筛选和详情接口。
3. 实现环境新增、更新、删除接口。
4. 实现保存前 SSH 测试接口。
5. 实现单环境 SSH 测试接口。
6. 实现批量 SSH 测试接口。
7. 使用 400、404、409、500 等标准状态码。
8. 统一返回字段命名和时间格式。
9. 密码按设计以明文返回，不进行脱敏或加密。

验收：接口契约与前端类型一致，非法参数和不存在资源有明确错误响应。

## 5. Vue 前端

1. 创建资源中心页面和 Pinia store。
2. 创建环境列表、筛选栏、状态标签和编辑抽屉。
3. 支持发布版本和环境类型切换。
4. 支持名称、地址和状态筛选。
5. 实现新建、编辑、删除和删除确认。
6. 实现普通文本密码输入和显示。
7. 实现保存前测试、单个测试和全部测试。
8. 测试期间只锁定当前按钮并显示加载状态。
9. 测试完成后刷新对应环境状态。
10. 保留复制 SSH 命令功能。
11. “更多”菜单只保留复制 SSH 命令和删除环境。
12. 保持现有原型的整体视觉风格。

验收：页面刷新后数据来自后端；所有操作不再依赖静态 mock 数据。

## 6. 测试与联调

1. 后端领域和服务单元测试。
2. H2 文件数据库集成测试。
3. REST API MockMvc 测试。
4. SSH 测试使用容器化 SSH 服务覆盖成功、认证失败和超时。
5. 前端类型检查和生产构建。
6. 前后端联调。
7. 使用真实 SSH 服务器完成最终人工验收。
8. 检查日志中没有密码内容。

## 7. 交付与文档

1. 添加开发启动说明。
2. 添加 H2 数据目录说明。
3. 添加真实 SSH 测试配置说明。
4. 添加前后端构建说明。
5. 更新领域模型和第一阶段设计文档中的实现状态。
6. 执行构建、测试和静态检查。
7. 提交实现代码和文档到远端 main 分支。

## 实施顺序

```
工程骨架
  -> H2/Flyway/领域模型
  -> 环境 CRUD
  -> SSH 测试
  -> REST API 完善
  -> Vue 资源中心
  -> 自动化测试
  -> 真实 SSH 联调
  -> 文档与提交
```

## 明确不做

- PostgreSQL 和 Docker 数据库
- 用户登录与权限
- 多用户协作
- 测试历史
- 测试进度和轮询
- SSH 密钥认证
- 跳板机
- 远程命令执行
- 工作目录和 MAE/OSMU 连通性检查
- 工作台、构建任务和部署任务联动
