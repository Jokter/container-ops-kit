# 环境工作区设计

## 目标

将资源中心重构为按发布版本管理构建环境和容器环境的高保真工作区。领域定义以 [domain-model.md](../../domain-model.md) 为唯一来源。

## 信息架构

资源中心顶部由发布版本选择器、版本名称、环境总数和可连接数量组成。主体使用“构建环境”和“容器环境”两个同级页签，不设置部署环境。

版本选择器展示版本编号和名称，例如 `R27C10 · 27B`。列表、统计、搜索、筛选和批量测试都限定在当前发布版本与当前环境类型内。

## 环境列表

工具栏包含搜索、连接状态筛选、测试全部和新增环境。环境列表展示环境名称、IP、系统架构、固定 SSH 用户、连接状态和最近测试时间。

每个环境提供测试连接、编辑、复制 SSH 命令、复制为新环境、停用和测试记录操作。复制为新环境只复制非密钥配置，密码必须重新填写。

连接状态分为未测试、测试中、可连接、连接失败和已停用。失败项展示简短原因；完整输出进入测试记录。

## 批量测试

“测试全部”测试当前发布版本、当前环境类型下的所有启用环境。页面逐行展示进度和结果，并汇总成功、失败与跳过数量，不以单一整体状态替代单项结果。

批量测试与单项测试使用同一连接测试规则。测试过程不得输出或保存明文密码。

## 环境编辑

编辑面板先选择环境类型和发布版本，再填写该类型的环境信息。固定 SSH 用户只读展示。

环境字段直接取自 [domain-model.md](../../domain-model.md) 中对应的环境定义，不在页面模型中建立第二套字段来源。

工作目录是后续远程操作的边界。页面提供的上传、下载、脚本和文件操作只能以该目录为根目录。

密码默认遮挡；编辑时留空表示不修改。系统架构使用 x86 和 ARM 两个界面选项，分别保存为 `x86_64` 和 `aarch64`。

## 页面状态

首次进入默认选择最新启用的发布版本和构建环境页签。没有环境时展示新增入口；没有测试记录时显示未测试；发布版本停用后环境只读展示，不允许新增或测试。

连接测试结束后仅更新连接状态、最近测试时间、耗时和失败摘要，不修改环境配置。

## 高保真范围

本轮在单页原型中实现发布版本切换、环境类型切换、状态筛选、单项测试、测试全部、新增或编辑面板、密码遮挡、系统架构选择和测试结果反馈。交互使用本地模拟数据，不接入真实 SSH。

构建、部署和容器运维工作区继续引用环境，不在各自页面维护环境副本。

## 验证

验证发布版本与环境类型切换、单项和批量测试状态、编辑字段、工作目录展示、密码遮挡，以及 1440、1024 和 700 三种宽度。现有构建和其他工作区交互不得退化。
